## How to Run

1. Clone the repository.

```bash
git clone <repository-url>
```

2. Open the repository in Visual Studio Code.

3. Navigate to the required practical folder.

4. Open `index.html` in Google Chrome or any modern web browser.

For example:

```text
Practical - 10/
└── Practical - 10.2/
    └── index.html
```

5. Run the HTML file in the browser.

No additional packages or external dependencies are required.
