### JavaScript Features Used

| Feature | Purpose |
|----------|---------|
| `var` | Used for variables with function scope and loop counters. |
| `let` | Used for variables whose values change during execution. |
| `const` | Used for fixed values such as GST rate and calculated totals. |
| Template Literals | Used to generate dynamic HTML content and formatted billing information. |
| Destructuring | Used to extract product properties from objects in a clean and readable manner. |

### Case Study Features

- Product listing with quantity selection
- Customer information form
- Automatic subtotal calculation
- GST calculation
- Grand total generation
- Invoice creation
- Dynamic webpage updates using JavaScript
