## Case Study

### Shopping Cart Calculator

A shopping cart calculator is developed using JavaScript arrays and array methods. The application allows users to add products to a shopping cart and automatically calculates product totals, cart total, discounts, and final payable amount.

## Features

- Add products to the shopping cart
- Store products using an array of objects
- Calculate individual product totals
- Calculate total cart amount
- Apply discounts based on cart value
- Calculate final payable amount
- Display products dynamically in a table
- Identify high-value products
- Generate item-wise summaries
- Validate user input

## JavaScript Array Methods Used

| Method | Purpose |
|---|---|
| `push()` | Adds a new product to the cart array. |
| `forEach()` | Iterates through products and displays them. |
| `map()` | Creates a summary of product amounts. |
| `filter()` | Finds products satisfying a particular condition. |
| `reduce()` | Calculates the total cart amount. |
