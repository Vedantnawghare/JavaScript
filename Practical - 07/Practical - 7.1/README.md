### JavaScript Features Used

| Feature | Purpose |
|----------|---------|
| Arrays | Stores and manages multiple tasks. |
| Objects | Stores task details such as ID, text, priority, due date, and completion status. |
| `push()` | Adds a new task to the task array. |
| `filter()` | Filters tasks and removes completed tasks. |
| `map()` | Updates the completion status of tasks. |
| `find()` | Finds a task using its unique ID. |
| `includes()` | Searches for a particular word or text in tasks. |
| DOM Manipulation | Dynamically creates and updates task elements. |
| Event Handling | Handles clicks, searching, and keyboard events. |
| Date Handling | Displays due dates and identifies overdue tasks. |

### Case Study Features

- Add new tasks
- Set task priority as Normal, Important, or Urgent
- Add due dates to tasks
- Mark tasks as completed
- Edit existing tasks
- Delete individual tasks
- Search tasks using the search bar
- Filter tasks by category
- Display total, completed, and remaining tasks
- Display task completion percentage
- Show overdue task status
- Clear all completed tasks

### Task Categories

The application provides the following task filters:

- **All Tasks:** Displays all available tasks.
- **Important:** Displays tasks marked as important.
- **Urgent:** Displays tasks marked as urgent.
- **Completed:** Displays only completed tasks.

### Progress Calculation

The completion percentage is calculated using the following formula:

```text
Completion Percentage =
(Completed Tasks / Total Tasks) × 100
````

The percentage is displayed in the progress card along with a progress bar.
