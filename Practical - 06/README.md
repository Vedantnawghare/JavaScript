## Case Study

### Social Media Login and Registration Page

A social media login and registration interface is developed using HTML, CSS, and JavaScript. The application provides separate login and sign-up forms with client-side validation for names, date of birth, gender, email address, phone number, password, and confirm password.

## Features

- Login form with email or phone number validation
- Registration form with first name and surname validation
- Date of birth validation
- Gender selection validation
- Email address validation
- Indian mobile number validation
- Real-time password requirement checking
- Uppercase letter validation
- Lowercase letter validation
- Digit validation
- Special character validation
- Minimum 8-character password validation
- Confirm password matching
- Dynamic error messages
- Switch between Login and Sign Up forms
- Successful login and account creation alerts

## JavaScript Validation Methods Used

| Method / Concept | Purpose |
|---|---|
| `addEventListener()` | Handles user interactions and form events. |
| `preventDefault()` | Prevents the form from submitting normally. |
| Regular Expressions | Validates names, email addresses, phone numbers, and passwords. |
| DOM Manipulation | Updates form elements and validation messages dynamically. |
| Conditional Statements | Checks whether user input satisfies the required conditions. |
| `.test()` | Checks whether input matches a regular expression pattern. |
| `.trim()` | Removes unnecessary spaces from user input. |
| `.includes()` | Checks whether specific characters or symbols are present. |
